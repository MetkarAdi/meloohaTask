This project is an astrology based qna application. 
stack - next.js + tailwind in /web ; fastapi in /api ; postgres on neon ; groq for LLMs. use multiple API keys as fallback options.
everything must be free tier
command `npm run dev` must install everything and start web + api together
use vedic astrology.
the LLM should never make up chart facts. the code computes facts and LLM can only use these facts. 
check documentation before using any library.
the web app must be responsive. higher priority to mobile layout
